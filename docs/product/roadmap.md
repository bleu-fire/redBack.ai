# Product Roadmap

## Phase 1 — Foundation

- Repository setup.
- Expo mobile shell.
- Express.js REST API.
- MongoDB / Mongoose schema.
- Authentication (JWT & bcrypt).

## Phase 2 — Identification MVP

- Camera scanner.
- Gallery upload.
- Image validation/storage.
- AI adapter.
- AI results screen.
- Species details.

## Phase 3 — Knowledge

- Species catalog ingestion.
- Search.
- Learning Center.
- Source attribution.

## Phase 4 — Production hardening

- AI evaluation dataset.
- Rate limiting.
- Observability.
- Backups.
- Privacy controls.
- App-store release preparation.

## Phase 5 — Optimization

- Better ranking/calibration.
- Faster image processing.
- Caching.
- Background jobs where justified.
